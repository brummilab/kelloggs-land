# HD graphics (shipped with the project)

Hand-drawn HD replacements for the game's tiles and sprites. The page loads them at start-up; players can switch them off under "Grafik-Werkstatt".

- File names end in `t_<hash>.png` (tile) or `s_<hash>.png` (sprite); a number prefix like `034_` is fine. Get them from the graphics workshop export (`hd-vorlage/`).
- Size: 4× the original (tile 64×64, sprite width·4 × height·4).
- Subfolders are fine (e.g. `level1/kacheln/`).
- `index.json` is generated by `tools/hd-index.py` when the site is published; don't edit it by hand.

How-to (German): [docs/HD-PAKET.md](../../docs/HD-PAKET.md).
